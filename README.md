# 🚀 Portafolio Web - [Tu Nombre]

¡Bienvenido a mi portafolio personal! Este proyecto es una vitrina interactiva para mostrar mis proyectos web, habilidades técnicas y experiencia en el desarrollo de software.

---

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido utilizando las siguientes herramientas y tecnologías:

* **Frontend:** React.js, Vite
* **Estilos:** Tailwind CSS, Framer Motion (para animaciones)
* **Control de Versiones:** Git & GitHub
* **Despliegue:** Vercel

---

## 💻 Proyectos Destacados

### 1. Agenda Web
* **Descripción:** Aplicación interactiva para la gestión de contactos y tareas pendientes con funcionalidades completas de edición, eliminación y creación.
* **Tech Stack:** JavaScript, CSS, Dockerfile.

### 2. Página Web Personal
* **Descripción:** Sitio web responsivo diseñado para presentar información personal, habilidades y proyectos.
* **Tech Stack:** React.js, Vite, Framer Motion, Tailwind CSS.
